# THRYN

THRYN is a fictional architecture studio website that I built to practice creating a modern, minimal, and responsive frontend design.

The idea behind THRYN was to create a website that feels calm, premium, and connected with nature. I focused on typography, spacing, colors, and creating a clean user experience similar to real architecture studio websites.

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features

- Responsive design for desktop and mobile
- Modern dark architecture-inspired theme
- Smooth scrolling navigation
- Scroll reveal animations
- Mobile navigation menu
- Clean typography and layout
